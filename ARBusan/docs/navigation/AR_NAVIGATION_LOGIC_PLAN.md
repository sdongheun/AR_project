# AR Navigation Logic Plan

이 문서는 메인 지도에서 `길찾기` 버튼을 누른 뒤 실행되는 AR 길찾기 로직 수정 과정을 추적한다. 목표는 바닥 전체에 화살표를 붙이는 방식이 아니라, 안정적인 `2D 방향 안내 + turn boundary 전방 3D 대형 화살표 + 도착 3D 핀` 구조를 만드는 것이다.

## 1. 현재 기준

- 길찾기는 메인 2D 지도에서 관광지 카드를 선택한 뒤 시작한다.
- 길찾기 화면에 들어오면 카메라/AR 화면이 열린다.
- 목적지는 선택된 관광지 1개만 사용한다.
- TMAP 보행자 길찾기 응답을 기준으로 경로와 마지막 도착 좌표를 사용한다.
- 바닥 전체 경로 화살표는 MVP에서 제외한다.
- 방향 전환 지점 좌표에 화살표를 정밀 고정하지 않는다.
- 사용자가 방향 전환 지점 바운더리 안에 들어오면 사용자 전방에 큰 3D 화살표를 띄운다.
- 도착 판정은 TMAP 마지막 도착 좌표 기준 5~15m 범위로 조정한다.

## 2. 수정 목표

```text
지도 핀 선택
-> 길찾기 버튼
-> AR 길찾기 화면 진입
-> 현재 위치와 목적지로 TMAP 보행자 경로 요청
-> 목적지 방향 2D 라벨/edge marker 표시
-> 경로에서 45도 이상 꺾이는 turn point 계산
-> 사용자가 turn boundary 안에 들어오면 전방 3D 대형 화살표 표시
-> turn point 통과 또는 방향 정렬 시 화살표 제거
-> 도착 좌표 5~15m 이내 진입 시 2D 라벨 숨김
-> 도착 3D 대형 핀 표시 후 길안내 종료
```

## 3. 체크리스트

### 3.1 길찾기 진입 상태 정리

- [ ] 메인 지도에서 선택한 관광지가 AR 길찾기 화면으로 정확히 전달되는지 재확인
- [ ] AR 길찾기 진입 시 선택 목적지 1개만 활성화
- [ ] 길찾기 모드 진입 시 기존 둘러보기/디버그 3D 마커가 남지 않도록 정리
- [ ] 길찾기 종료/뒤로가기 시 route 상태와 3D 엔티티 정리
- [ ] 테스트: 길찾기 버튼 클릭 시 선택한 관광지 이름이 AR 화면 목적지로 표시되는지 확인

### 3.2 TMAP 경로 요청/캐시 정리

- [ ] 현재 위치와 목적지 POI 기준으로 TMAP 보행자 경로 요청
- [ ] TMAP 응답의 route 좌표 개수 로그 정리
- [ ] route 전체 길이와 마지막 도착 좌표 로그 정리
- [ ] 같은 목적지/비슷한 시작점에서는 기존 캐시 재사용
- [ ] TMAP 실패 시 POI 좌표 fallback을 명확히 표시
- [ ] 테스트: 길찾기 시작 시 route 좌표와 마지막 도착 좌표가 로그에 표시되는지 확인

### 3.3 목적지 2D 방향 라벨/edge marker 정리

- [ ] 목적지 기준 좌표를 TMAP 마지막 도착 좌표로 통일
- [ ] 목적지가 화면 안에 있으면 2D 방향 라벨 표시
- [ ] 목적지가 화면 밖이면 edge marker 표시
- [ ] 도착 근처에서는 2D 라벨/edge marker 숨김
- [ ] 테스트: 카메라 방향을 돌릴 때 목적지 방향 라벨/edge marker가 자연스럽게 바뀌는지 확인

### 3.4 turn point 계산

- [ ] TMAP route polyline에서 연속 segment bearing 계산
- [ ] 직진 대비 45도 이상 꺾이는 지점을 turn point 후보로 선택
- [ ] 좌회전/우회전 방향 계산
- [ ] 너무 가까운 turn point 중복 제거
- [ ] turn boundary 반경 기준 정의
- [ ] 테스트: 로그에 turn point 개수, 좌/우 방향, 내 위치와의 거리가 표시되는지 확인

### 3.5 전방 3D 대형 화살표

- [ ] 사용자가 turn boundary 안에 들어왔는지 계산
- [ ] 화살표를 turn point 좌표가 아니라 사용자 전방 2~4m에 생성
- [ ] 화살표 높이는 바닥이 아니라 기기 높이 근처로 설정
- [ ] 좌회전/우회전 방향에 맞게 화살표 회전
- [ ] 낮에도 보이는 파란색 계열 대형 3D 화살표 사용
- [ ] turn point 통과 또는 방향 정렬 시 화살표 제거
- [ ] 테스트: 회전 지점 근처에서만 큰 화살표가 보이는지 확인

### 3.6 도착 판정/도착 핀

- [ ] 현재 위치와 TMAP 마지막 도착 좌표 거리 계산
- [ ] 도착 기준을 5~15m 범위로 적용
- [ ] 도착 시 길안내 상태 종료
- [ ] 도착 시 목적지 2D 라벨/edge marker 숨김
- [ ] 도착 시 3D 대형 핀 표시
- [ ] 도착 상태 UI 문구 표시
- [ ] 테스트: 도착 좌표 근처에서 길안내가 종료되고 3D 핀이 뜨는지 확인

### 3.7 안정화/성능

- [ ] route 재요청 빈도 제한
- [ ] AR 엔티티 재생성 최소화
- [ ] 동일 로그 중복 출력 제한
- [ ] 위치 정확도가 낮을 때 3D 표시를 과감히 줄이고 2D 안내 유지
- [ ] 앱 발열이 심해지는 기능이 켜져 있는지 점검
- [ ] 테스트: 5분 이상 길찾기 화면을 켜도 과도한 발열/깜빡임이 없는지 확인
