회전 지점 3D 화살표 표시 로직

ARBusan 길찾기 · AR_NAVIGATION_LOGIC_PLAN.md 3.4 / 3.5 + 3.6 게이트

핵심 원칙: 3D 화살표는 회전 지점의 실제 GPS 좌표에 꽂지 않는다. 위치·heading이 흔들리는 도심에서 좌표 고정 화살표는 엉뚱한 도로·건물 위에 보이기 때문이다. 대신 “지금 회전해야 한다”는 행동 신호로 취급해, 조건이 맞을 때만 카메라 전방에 띄운다.

1. 한눈에 보는 판단 흐름

매 위치/heading 갱신마다 refreshRouteArrowPath() → routeArrowSnapshots() 가 아래 순서로 평가한다. 하나라도 막히면 화살표는 표시되지 않는다.

  1. 길찾기 모드 ON · 목적지 선택됨 · 현재 위치(origin) 있음 · TMAP 경로 있음 아니면 표시 안 함
  2. 도착 판정: 도착 좌표까지 ≤ 10m 이면 화살표 대신 도착 핀으로 전환 10m 이내면 화살표 종료
  3. 3.6 위치 안정화 게이트 — guidanceFix.allowsTurnCommitment. 위치가 불안정 또는 위치 유지(튐) 상태면 좌/우를 확정하지 않으므로 화살표를 만들지 않는다 불안정이면 표시 안 함
  4. 현재 위치에서 가장 가까운 경로점을 찾고, 그 지점부터 앞쪽 경로점들을 회전 후보로 스캔
  5. 각 후보점에서 전후 6m 지점을 샘플링해 진입 방위(incoming)·진출 방위(outgoing)·회전각(signedTurn)·내 거리(distanceFromOrigin) 계산
  6. 회전각 |signedTurn| ≥ 45° 인가? 예: 다음아니오: 회전 아님
  7. 오차 원 turn boundary: (거리 − horizontalAccuracy) ≤ 18m 인가? (GPS 오차 원이 boundary와 겹치면 회전 준비로 인정) 예: 다음아니오: boundary 밖
  8. 회전 지점을 보고 있나? 카메라 heading과 목표 방위 차이 ≤ 60° (가까우면 진출 방위, 아니면 회전점 방위 기준) 예: 다음아니오: 회전점 안 봄
  9. 이미 돌았나? heading이 진출 방위와 ≤ 22° 로 정렬됐으면 회전 완료로 보고 숨김 정렬됨: 화살표 제거
  10. 화살표 생성 — 카메라 전방 3m, 기기 높이(−0.05m)에 1개. 회전각 부호로 좌/우 결정(signedTurn > 0 → 우회전). 최대 1개.

2. 회전 후보 계산 (top-down)

경로 polyline에서 꺾이는 지점을 찾는 방식과, 화살표가 켜지는 공간 조건을 위에서 내려다본 그림이다.

3. 화살표 배치 (카메라 기준, 좌표 고정 아님)

조건이 모두 통과하면 화살표는 회전점이 아니라 생성 순간의 카메라 전방에 만들어진다. RealityKit AnchorEntity(world: cameraTransform) 으로 월드에 고정되므로 GPS·지면 raycast의 영향을 받지 않는다.

변경 예정 (UX 결정): 현재는 카메라 transform(시선) 기준이라 사용자가 바닥을 보거나 두리번거리면 화살표가 시선을 따라 엉뚱한 곳에 뜰 수 있다. 이를 “기기 위치 + 휴대폰 높이 + 가는 방향(경로 방위), 중력 정렬” 앵커링으로 교체한다 (카메라에서 위치만 쓰고 회전은 쓰지 않음). 상세 규칙은 AR_NAVIGATION_LOGIC_PLAN.md 3.10.

4. 화살표가 사라지는 조건

  • 방향 정렬: heading이 진출 방위와 22° 이내로 맞으면 “회전 완료”로 보고 제거
  • boundary 이탈: 회전점까지(오차 원 반영) 18m를 다시 벗어나면 숨김
  • 회전점을 안 봄: 카메라가 회전점 방향에서 60° 넘게 벗어나면 숨김
  • 도착: 도착 좌표 10m 이내 진입 시 화살표 종료, 도착 핀으로 전환
  • 위치 불안정(3.6): 정확도 저하·경로 이탈·위치 튐 유지 상태면 화살표를 만들지 않음

5. 핵심 상수 (현장 튜닝 대상)

상수값의미
routeArrivalCompletionMeters10 m도착 판정 → 화살표 종료/도착 핀
routeTurnMinimumAngleDegrees45°이 이상 꺾여야 회전으로 인정
routeTurnSampleDistanceMeters6 m회전점 전·후 방위 샘플 거리
routeTurnBoundaryMeters18 m회전 준비로 인정하는 거리(오차 원만큼 확장)
routeArrowFacingToleranceDegrees60°회전점을 “보고 있다”고 볼 시야 허용치
routeTurnAlignedThresholdDegrees22°이 이내로 정렬되면 회전 완료(숨김)
routeArrowLookAheadMeters120 m이보다 먼 회전 후보는 무시
routeArrowForwardDistanceMeters3.0 m카메라 전방 화살표 거리
routeArrowCameraHeightOffsetMeters−0.05 m화살표 높이(기기 높이 근처)
maxRouteArrowCount1동시에 띄우는 화살표 개수
참고: 회전 후보·좌우·내 거리는 routeArrowComputationDiagnostics 로그로, 위치/방향 안정화 상태는 navigationStabilityDiagnostics 로 실시간 확인된다. 화살표가 안 뜨면 위 게이트 중 어디서 막혔는지 로그에 사유가 남는다.
