# ARBusan 실기기 테스트 기록

이 문서는 사용자가 현장에서 테스트한 조건과 결과를 잊지 않기 위해 기록한다. 구현 변경 이력은 `../../ARBusan_PROJECT_STATUS.md`에 섞지 않고, 여기에는 테스트 당시의 설정과 관찰 결과만 남긴다.

## 기록 방식

각 테스트는 아래 항목으로 정리한다.

- 테스트 날짜
- 테스트 위치
- 앱 설정
- 바라본 대상
- 화면에 표시된 후보
- 최종 인식 결과
- 판단
- 다음 확인 사항

## 2026-05-23 테스트

### 테스트 1: 수동 후보 없음 상태에서 건물 바라보기

- 테스트 위치: 김해 인제대 인근 목업 건물 주변
- 앱 설정:
  - `VPS/위치 후보`: 없음
  - `브이월드 Polygon 후보`: 없음
  - `OCR 입력`: 카메라 OCR 자동 입력 사용
  - `카메라 방향 후보`: 앱이 현재 위치와 카메라 heading으로 자동 계산
- 바라본 대상:
  - 투썸플레이스, 올리브영, 후참잘 중 실제 카메라로 비춘 목업 건물
- 관찰 결과:
  - 수동으로 `VPS/위치 후보`와 `브이월드 Polygon 후보`를 설정하지 않아도, 해당 건물을 바라보면 해당 건물로 `인식함 (보통)`이 표시됨
- 판단:
  - 현재 MVP 로직 기준으로 정상 동작이다.
  - 수동 후보가 없는 상태에서는 공간 검증 신호가 없으므로 `높음`이 아니라 `보통`으로 뜨는 것이 맞다.
  - 이 결과는 `OCR` 또는 `카메라 방향 후보` 기반 자동 인식이 동작하고 있음을 의미한다.
- 다음 확인 사항:
  - 각 건물별로 `카메라 방향 후보`가 실제 바라본 건물과 일치하는지 반복 확인한다.
  - `OCR`과 `카메라 방향 후보`가 같은 건물을 가리킬 때 신뢰도를 `높음`으로 올릴지 결정한다.
  - heading이 반대로 나오거나 옆 건물로 자주 밀리면 카메라 방향 보정값과 각도 허용범위를 조정한다.

### 테스트 2: 수동 후보를 특정 건물로 설정한 상태

- 테스트 위치: 김해 인제대 인근 목업 건물 주변
- 앱 설정:
  - `VPS/위치 후보`: 사용자가 바라볼 건물로 수동 설정
  - `브이월드 Polygon 후보`: 사용자가 바라볼 건물로 수동 설정
  - `OCR 입력`: 카메라 OCR 자동 입력 사용
- 바라본 대상:
  - 수동 후보로 설정한 건물
- 관찰 결과:
  - 해당 건물을 바라보면 `건물 인식됨 (높음)`으로 표시됨
  - 수동 후보를 설정하고 해당 건물을 바라보지 않으면 `건물 인식됨 (보통)` 또는 공간 후보 기반 결과가 표시됨
- 판단:
  - 수정 전 확인된 정상 동작이다.
  - 다만 사용자가 원하는 최종 MVP는 수동 세팅 없이 자동으로 바라본 건물이 뜨는 방식이므로, 이 테스트는 기준 비교용으로만 사용한다.
- 다음 확인 사항:
  - 앞으로는 기본 테스트를 `VPS/위치 후보 없음`, `브이월드 Polygon 후보 없음` 상태에서 진행한다.
  - 수동 후보 테스트는 오인식/충돌 방지 확인이 필요할 때만 수행한다.
