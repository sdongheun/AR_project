# Main 2D Map Plan

이 문서는 ARBusan의 메인 화면 2D 지도 작업을 추적한다. 현재 앱 방향은 상시 카메라 AR이 아니라, 일반 지도에서 관광지를 탐색하고 길찾기 버튼을 눌렀을 때 AR 길안내로 전환하는 구조다.

## 1. 목표

- 앱 첫 화면은 TMAP 네이티브 2D 지도다.
- 앱 실행 직후 사용자의 현재 위치를 지도 중심에 표시한다.
- 현재 테스트 범위는 내 위치 기준 3km다.
- 현재 표시 데이터는 김해 TourAPI 후보와 목업 건물이다.
- 추후 최종 데이터는 부산 TourAPI 관광지만 사용한다.
- 관광지 마커 선택 시 하단 플로팅 카드가 뜬다.
- 카드 버튼을 통해 정보 화면 또는 AR 길찾기 화면으로 전환한다.

## 2. 데이터 표시 규칙

### 현재 MVP

- 목업 건물: 투썸플레이스, 후참잘, 올리브영
- TourAPI: 현재 테스트 지역 기준 김해 후보
- 표시 범위: 사용자 현재 위치 기준 3km
- 마커 색상:
  - 목업 건물: 테스트용 색상
  - TourAPI 관광지: 관광지용 색상
  - 선택된 마커: 강조 색상

### 추후 전환

- 김해 TourAPI와 목업 건물은 테스트 모드로 분리한다.
- 실제 서비스 모드는 부산 TourAPI 관광지만 표시한다.
- 테스트/서비스 모드 전환은 코드에서 명확히 구분한다.

## 4. 다음 작업 순서

1. 현재 위치 중심 지도부터 안정화한다.
2. 지도 표시 범위를 3km로 바꾸고 목업/TourAPI 마커 색상을 분리한다.
3. 하단 플로팅 카드의 이미지 영역은 placeholder 유지 후 실제 이미지 연결은 후속으로 둔다.
4. 정보보기/길찾기 전환이 선택 관광지 상태를 제대로 넘기는지 확인한다.

## 5. 테스트 기준

- 앱을 켰을 때 지도 중심이 내 현재 위치 주변이어야 한다.
- 현재 위치 기준 3km 밖 후보는 표시하지 않는다.
- 목업 건물과 TourAPI 관광지는 색상만 봐도 구분되어야 한다.
- 마커를 누르면 하단 카드가 떠야 한다.
- 정보보기는 상세 placeholder로 이동해야 한다.
- 길찾기는 AR 길찾기 화면으로 이동해야 한다.
