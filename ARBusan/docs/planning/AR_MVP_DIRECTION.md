# ARBusan AR MVP Direction

이 문서는 공모전 MVP 기준을 다시 고정하기 위한 현재 활성 방향이다. 이전 상시 카메라/3D 외벽 부착형 실험은 보존하되, 기본 UX 기준으로 삼지 않는다.

## 1. 결론

MVP는 `2D 지도 기반 관광지 탐색 + 필요할 때만 카메라 AR 길찾기`로 간다.

정밀한 3D 오브젝트를 실제 건물/바닥 좌표에 완벽히 붙이는 방식은 한국 테스트 환경에서 안정성이 부족했다. 따라서 AR은 “정확히 붙이는 기술”보다 “사용자가 어느 방향으로 가야 하는지 직관적으로 안내하는 화면”으로 제한한다.

## 2. 핵심 UX

```text
앱 실행
-> 일반 2D 지도 표시
-> TourAPI 관광지를 지도 핀으로 표시(현재 위치 기준 3km)
-> 사용자가 관광지 핀 선택
-> 관광지 라벨/카드 표시(사진, 정보보기, 길찾기)
-> 정보보기: 상세 정보 창으로 전환(1차 MVP는 창만 구성)
-> 길찾기: 카메라/AR 화면 실행
-> TMAP 보행자 경로 요청
-> 목적지 방향은 2D 라벨/edge marker로 안내
-> TMAP 경로가 크게 꺾이는 지점의 바운더리 진입 시 전방에 좌/우 3D 대형 화살표 표시
-> TMAP 마지막 도착 좌표 5~15m 이내에서는 길안내 종료
-> 도착 상태에서는 3D 대형 핀/도착 표시를 강조
```

## 3. 화면 구성

- 메인 화면: 일반 2D 지도와 TourAPI 관광지 핀
- 관광지 라벨/카드: 사진, 정보보기, 길찾기 버튼
- 정보보기 화면: 1차 MVP에서는 새 창 전환만 구현
- AR 길찾기 화면: 길찾기 버튼을 눌렀을 때만 카메라 실행
- 2D 방향 라벨/edge marker: 목적지가 화면 밖일 때 방향 안내
- AR 안내판: “직진”, “오른쪽으로 이동”, “50m 후 회전” 같은 큰 안내
- 3D 회전 화살표: 꺾임 지점 좌표에 직접 꽂지 않고, 꺾임 바운더리 안에서 사용자 전방에 표시
- 3D 목적지 핀: 도착 근처에서만 강조 표시

## 4. 유지할 기능

- SwiftUI + ARKit/RealityKit 카메라 화면
- ARCore Geospatial/CoreLocation 위치 수신
- heading/pose 기반 방향 계산
- TourAPI 후보 로딩 구조
- TMAP 보행자 경로와 마지막 도착 좌표
- 2D 지도 핀/라벨 구조
- 2D 방향 라벨/edge marker
- 위치 신뢰도/경로/도착 좌표 기본 로그

## 5. 기본 비활성/보류 기능

- 건물 외벽 Polygon에 3D 구체/텍스트를 붙이는 방식
- VWorld Polygon 기반 정문/대표점 자동 계산
- matrix/polygon 디버그 마커
- Scene Semantics/OCR 기반 후보 보정
- 지면에 정확히 붙는 바닥 화살표
- 방향 전환 좌표에 3D 화살표를 정밀 고정하는 방식
- 여러 POI를 동시에 정밀 3D Anchor로 띄우는 방식

보류 기능은 삭제하지 않는다. `FeatureFlags`로 기본 비활성화하고, 필요할 때만 다시 켠다.

## 6. 성공 기준

- 공모전 시연에서 앱이 안정적으로 실행된다.
- 사용자는 2D 지도에서 3km 이내 TourAPI 관광지를 핀으로 확인할 수 있다.
- 관광지 핀을 누르면 사진/정보보기/길찾기 버튼이 있는 라벨이 뜬다.
- 카메라 화면에서는 큰 방향 안내가 흔들림 없이 읽힌다.
- 목적지 선택 후 TMAP 경로와 도착 좌표가 로그/화면에 반영된다.
- 길찾기 중에는 영상 레퍼런스처럼 진행 방향 안내가 보이고, 좌/우 회전 바운더리 안에서는 사용자 전방에 3D 대형 화살표가 보인다.
- 바닥 전체를 잇는 점선/화살표는 지면 고도 차이로 어색해질 수 있어 기본 MVP에서 제외한다.
- TMAP 도착 좌표 기준 5~15m 이내에 들어오면 길안내가 종료되고 도착 핀 상태로 전환된다.
- AR 요소가 불안정할 때도 2D 지도/방향 라벨이 길찾기 기준점을 제공한다.

## 7. 다음 구현 순서

1. 2D 지도 메인 화면으로 전환
2. TourAPI 3km 관광지 핀 표시
3. 관광지 핀 선택 카드 구현(사진, 정보보기, 길찾기)
4. 정보보기 새 창 구현
5. 길찾기 버튼에서만 AR 카메라 실행
6. TMAP 경로 기반 다음 행동 안내 문구 계산
7. 목적지 2D 방향 라벨/edge marker 정리
8. 좌/우 회전 바운더리 진입 시 전방 3D 대형 화살표 표시
9. 도착 5~15m 길안내 종료와 3D 대형 핀 상태 구현

길찾기 로직 수정은 [`../navigation/AR_NAVIGATION_LOGIC_PLAN.md`](../navigation/AR_NAVIGATION_LOGIC_PLAN.md)를 기준으로 순차 진행한다.
