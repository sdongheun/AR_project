# ARBusan AR MVP Direction

이 문서는 공모전 MVP의 **현재 활성 방향**을 고정한다.

> 변경 이력: 초기에는 *"2D 지도 + 필요할 때만 AR 길찾기"* (길찾기 중심) MVP였다. 이후 부산 측위 한계
> (GPS 오차·VPS 커버리지 불안정·자기 간섭)로 정밀 AR 길안내가 깨지기 쉬워 **AR 관광 체험 중심**으로 재정렬했다.
> 길찾기 중심 시절의 상세(회전 화살표·곡선 리본·출발 방향 등)는 `../navigation/` 문서와 git 이력에 보존(현재 제거됨).

## 1. 결론

**MVP = "AR 관광 체험 앱"** 이다. 정체성은 **카메라로 관광지를 발견하고, 도착해서 AR로 인증샷을 찍고 스탬프를 모으는 체험**이다. 길찾기는 그 체험으로 데려다주는 **보조**다.

핵심 원칙: **AR은 가까울 때(VIO가 앵커를 단단히 잡을 때) 견고하다.** 따라서 진짜 3D AR은 **도착 근거리**에 몰아넣고, 원거리(인식·길찾기)는 위치/heading 오차에 강한 **가벼운 2D**로 둔다. 절대 정밀 위치에 의존하지 않는다.

## 2. 왜 이 방향인가 (부산 현실)

- GPS는 도심에서 수~수십 m 튀고, VPS는 한국 스트리트뷰 의존이라 부산 커버리지가 불안정하며, Apple geo-tracking은 한국 미지원, 자기장 간섭으로 heading도 틀어진다.
- 좌표에 3D를 정밀 고정하면 오차가 그대로 드러나 신뢰도가 떨어진다 → **원거리 정밀 AR은 포기**.
- 대신 **근거리 AR 체험**(도착 포토존)은 VIO로 견고하고 임팩트가 크다 → 여기에 AR 정체성을 집중.
- 관광지가 상업 POI(쇼핑몰·맛집·자연) 중심이라 "역사 설명"은 약함 → **정보 전달보다 발견·체험·수집**으로 차별화.

## 3. 세 기둥

### 3.1 카메라 관광지 인식 (메인 ①)
- 카메라로 주변을 비추면 "이게 뭐다"를 알려준다.
- 기술: **기하(현재 위치+heading → 시야 콘 매칭) + OCR(간판) + 신뢰도 점수**. (엔진 대부분 구현됨)
- 표시: **견고한 2D 태그**(이름/거리). 위치가 튀어도 정체는 OCR로 보장, 태그는 스무딩·재투영으로 자동 복귀(월드 고정 3D로 안 붙임).
- 차별화: 단순 정보 나열이 아니라 **탐색·발견 + 수집/체험**으로 연결.

### 3.2 도착 AR 포토존 + 스탬프 (메인 ② · AR 정체성·와우)
- 근거리 도착 → 도착 핀 터치 → **관광지 3D 타이포(효과 기반 공간 AR)** → 걸어서 각도+핀치/회전 → 촬영 → **스탬프 수집**.
- 효과 기반(타이포+빛)이라 취향 안 타고(촌스러움 회피) 아트 부담 적으며 인스타 친화.
- 상세: [`../experience/PHOTO_ZONE_STAMP_MVP.md`](../experience/PHOTO_ZONE_STAMP_MVP.md).

### 3.3 길찾기 (보조 · 완성)
- **2D 지도(TMAP)가 실제 라우팅**을 담당.
- AR은 **목적지 표시만**: 먼 거리 = 2D 라벨/가장자리 지시(폴리곤 인식, 화면 밖이면 방향 화살표), 근거리(≤30m) = 3D 빨간 핀(공간 고정).
- **회전 화살표·곡선 리본·출발 방향 라벨·턴바이턴은 제거됨.**
- 견고성: 경로 이탈 재탐색(§4-A), 트래킹 상실 강등(§4-B), 북 재보정(§4-C) 유지.

## 4. 셸 / 사용자 여정

```text
메인 = 2D 지도 + 관광지 핀 + 하단 타원 플로팅 메뉴바(지도/탐색/기록)
  · 핀 선택  → 플로팅 바 내려가고 길찾기 박스(정보보기/길찾기) 등장
  · 빈 곳 탭 → 박스 닫히고 플로팅 바 복귀

여정: 둘러보기(인식) → 이동(길찾기, 가볍게) → 도착 체험(포토존+스탬프)
```

## 5. 설계 원칙

- 2D 지도는 길찾기의 신뢰 기준. AR은 정밀 좌표 고정이 아니라 체험/방향 보조.
- 위치는 점이 아니라 권역으로, heading은 이동 방향·최근 안정값과 함께 판단.
- 센서 불안정 시 AR을 약화하고 2D/텍스트로 강등(정직).
- 진짜 3D는 근거리(VIO)에만, 원거리는 2D. "정확(VPS 양호/근거리)하면 3D로 승격" 적응형.
- AR 콘텐츠는 **효과 기반(타이포·빛)** 또는 **사용자 실사진** 우선 — 커스텀 캐릭터의 취향/완성도 리스크 회피.

## 6. 제거됨 / 비활성

- (제거) 회전 화살표, 곡선 바닥 리본, 출발 방향 라벨, 턴바이턴 — git 이력 보존.
- (보류, FeatureFlag) 건물 외벽 3D 부착, VWorld 자동 정문, matrix/marker 디버그, Scene Semantics, 다중 정밀 3D Anchor.

## 7. 성공 기준

- 시연에서 안정 실행.
- 지도에서 관광지 핀 확인 → 선택 카드(사진/정보/길찾기).
- 카메라로 주변 관광지를 비추면 견고한 2D 태그로 식별.
- 길찾기: 2D 지도로 정확히 안내 + 목적지 표시(원거리 2D/근거리 3D 핀)가 흔들림 없이.
- 도착 시 핀 터치 → 공간 AR 타이포로 인증샷 + 스탬프 획득(유치하지 않고 인스타 가능).
- GPS/heading이 조금 틀려도 사용자가 다음 행동/정체를 이해.
