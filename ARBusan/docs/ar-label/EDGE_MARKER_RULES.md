# ARBusan Edge Marker Rules

이 문서는 `../planning/AR_TECH_ROADMAP.md`의 `6.4.6 projection 기반 라벨 안정화` 자식 문서다. 화면 안/밖 표시 규칙과 3D 마커 전환 후의 UX 기준을 정리한다.

## 1. 현재 판단

- 2D overlay 기준의 최소 라벨/마커 안정화는 완료했다.
- 기존 3D 외벽 부착형 실험은 위치감은 확인했지만, 가까운 건물/위치 흔들림/도심 환경에서 안정성이 부족했다.
- 앞으로는 3D 텍스트를 외벽에 붙이는 방식보다 `2D 지도 탐색 + 길찾기 AR 화면 + 목적지 2D 방향 라벨/edge marker + turn boundary 3D 화살표 + 도착 3D 핀` 조합을 기본으로 한다.
- 3D 상세 계획은 `3D_LABEL_REFINEMENT_PLAN.md`, 안정화 계획은 `3D_LABEL_OPTIMIZATION_PLAN.md`에서 관리한다.

## 2. 표시 역할

```text
2D 지도:
    앱 메인 화면
    현재 위치 기준 1km 이내 TourAPI 관광지 핀을 표시

관광지 카드:
    지도 핀 선택 시 사진, 정보보기, 길찾기 버튼 표시

2D 방향 라벨/edge marker:
    AR 길찾기 중 목적지 방향을 안내

3D 회전 화살표:
    45도 이상 꺾이는 turn point 바운더리 안에서 사용자 전방에 표시

3D 도착 핀:
    TMAP 마지막 도착 좌표 기준 5~15m 이내 진입 시 표시

정보 표시:
    정보보기 버튼은 1차 MVP에서 새 창 전환

디버그 마커:
    matrix, 핑크/주황 후보, Polygon 로그 등 개발 검증용
```

## 3. 화면 안 표시 규칙

- 둘러보기 모드에서는 카메라를 상시 켜지 않는다.
- 주변 후보는 일반 2D 지도 핀으로 표시한다.
- 카메라 화면은 길찾기 버튼을 누른 뒤에만 사용한다.
- AR 길찾기 중에는 목적지 방향 라벨만 우선 표시한다.
- 화면 안에 들어온 후보가 1개면 해당 후보의 2D 정보 카드를 표시한다.
- 화면 안에 후보가 여러 개면 중심 후보를 우선 카드로 표시하고, 나머지는 짧은 이름 마커로 표시한다.
- 현재 테스트 색상:
  - 중심 후보: 핑크
  - 나머지 화면 안 후보: 주황
- 핑크/주황 마커는 최종 UX가 아니라 검증용이다.
- 추후 짧은 이름 마커를 탭하면 해당 후보를 정보 카드로 승격한다.

## 4. 화면 밖 edge marker 규칙

- AR 길찾기 중 목적지가 화면 밖이면 edge marker로 표시한다.
- 둘러보기 모드에서는 일반 2D 지도가 기본이므로 edge marker를 쓰지 않는다.
- 최대 3개까지 표시한다.
- 후보가 화면 밖이면 라벨은 숨기고 edge marker만 보인다.
- edge marker는 좌/우/상/하 가장자리를 모두 사용할 수 있다.
- 180도 반대 방향 후보는 화면 중앙에 나오지 않고, signed angle 기준으로 왼쪽 또는 오른쪽 가장자리에 붙인다.
- 같은 방향에 여러 marker가 겹치면 우선 세로로 쌓고, 지저분하면 `+N` 묶음을 검토한다.

## 5. 거리별 표시

```text
0~120m:
    둘러보기: 2D 지도 핀/카드
    길찾기: 2D 방향 라벨 + turn boundary 3D 화살표 + 도착 3D 핀

120m~1km:
    3D 마커 숨김
    2D 지도, 2D 방향/거리 카드, edge marker 중심

1km 이상:
    기본 후보에서 제외하거나 제한적으로 방향만 안내
```

건물형 거리 기준:

- 사용자 위치에서 TMAP 마지막 도착 좌표까지의 거리

비건물형 거리 기준:

- 사용자 위치에서 TMAP 마지막 도착 좌표까지의 거리
- TMAP 결과가 없으면 TourAPI POI 좌표까지의 거리

## 6. 3D 마커와 2D 카드 연결

- 3D 도착 핀은 길찾기 종료 시 선택 목적지의 도착 지점 위치감을 주는 용도다.
- 현재 2D 카드는 과도기 UI다.
- 정보보기는 관광지 카드의 버튼으로 새 창을 연다.
- 길찾기 중 목적지가 화면 안에 있으면 2D 방향 라벨을 표시한다.
- 목적지가 화면 밖이면 edge marker가 방향을 안내한다.
- 둘러보기 모드에서는 3D 마커보다 일반 2D 지도가 후보 탐색의 기준이다.

2D 카드 예시:

```text
후참잘
31m / 오른쪽 앞
```

## 7. 방향 문구

사용자 heading과 대상 bearing 차이를 기준으로 방향 문구를 만든다.

```text
정면: -25도 ~ +25도
왼쪽 앞 / 오른쪽 앞: 25도 ~ 75도
왼쪽 / 오른쪽: 75도 ~ 115도
왼쪽 뒤 / 오른쪽 뒤: 115도 ~ 155도
뒤쪽: 155도 ~ 180도
```

방향 문구는 smoothing을 적용한다. 짧은 시간에 `오른쪽 앞`과 `오른쪽`이 반복되면 마지막 안정 방향을 유지한다.

## 8. 디버그 UI 기준

기본 화면에는 필수 상태만 둔다.

- API 키 상태
- VPS/위치 요약
- 활성 3D Anchor 개수
- 현재 후보/선택 결과
- 데이터 상태

전체 로그 보기에서만 표시한다.

- VWorld Polygon 후보 상세
- WGS84 Anchor 요청/완료/실패
- TMAP 경로 마지막 도착 좌표
- TMAP turn point와 turn boundary 상태
- ENU 좌표
- matrix 투영 로그
- 기존 외벽 후보점 계산 로그

Scene Semantics와 OCR은 현재 메인 로직에서 제외했으므로 기본 로그에 노출하지 않는다.
